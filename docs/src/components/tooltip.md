## API

| 属性 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| content | 提示内容 | `string` | `''` |
| placement | 位置 | `top` \| `bottom` \| `left` \| `right` | `top` |
| placement | 位置扩展 | `topLeft` \| `topRight` \| `bottomLeft` \| `bottomRight` \| `leftTop` \| `leftBottom` \| `rightTop` \| `rightBottom` | - |
| trigger | 触发方式 | `hover` \| `click` | `hover` |
| visible | 受控显示 | `boolean` | `undefined` |
| disabled | 禁用 | `boolean` | `false` |
